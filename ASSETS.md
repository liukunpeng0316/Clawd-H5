# Asset Policy

The source code in this repository is licensed under the MIT License. The
included image and animation assets are not automatically covered by that same
permission.

## Included Assets

`assets/` and `wechat_stickers/` contain Clawd-related SVG, GIF, and caption
material used to demonstrate and guide the animation workflow. Reference assets
are separated by provenance:

- `assets/upstream/` — 11 base animations referencing the open-source
  [clawd-tank](https://github.com/marciogranzotto/clawd-tank) project (MIT).
- `assets/original/` — 43 animations authored in this repository, plus the
  `clawd-body-structure.md` spec. The sticker GIFs in `wechat_stickers/` are
  exported from these original SVGs.

These assets are included for research, development, and reference use. Do not
assume they are cleared for commercial redistribution, product branding, or
merchandising.

## Source And Attribution

Clawd's base character design references the open-source
[clawd-tank](https://github.com/marciogranzotto/clawd-tank) project (MIT); the
`assets/upstream/` animations build on those base assets. The `assets/original/`
animations were authored in this repository and are covered by this project's
MIT `LICENSE`.

Note that a file license covers the asset *files*, not the Clawd character
itself. "Clawd" is Anthropic's mascot; reuse of the character likeness for
branding or merchandising may require separate permission from the rights holder.

## Commercial Use

If you want to use the included Clawd assets commercially, replace them with
assets you own or obtain explicit rights from the relevant rights holder.

## Workspace Output

Files written to `workspace/` are local working outputs. Review their content
and rights before publishing or promoting them into `assets/` or
`wechat_stickers/`.
