# Clawd 角色身体结构参考

## 基础骨架 (clawd-static-base.svg)

Clawd 是一个完全由矩形构成的像素艺术角色，所有部件均为 `<rect>` 元素。

### 颜色
- 身体颜色: `#DE886D` (鲑鱼色/赤陶色)
- 眼睛颜色: `#000000` (黑色)
- 地面阴影: `#000000`, opacity 0.5

### 身体部件坐标 (基于 15x16 单位画布)

| 部件 | 位置 (x, y) | 尺寸 (w x h) | 说明 |
|------|-------------|--------------|------|
| 躯干 (torso) | (2, 6) | 11 x 7 | 主体矩形，最大的部件 |
| 左眼 (left-eye) | (4, 8) | 1 x 2 | 黑色竖向小矩形（普通睁眼） |
| 右眼 (right-eye) | (10, 8) | 1 x 2 | 黑色竖向小矩形（普通睁眼） |
| 左臂 (left-arm) | (0, 9) | 2 x 2 | 躯干左侧 |
| 右臂 (right-arm) | (13, 9) | 2 x 2 | 躯干右侧 |
| 左外腿 (outer-left-leg) | (3, 13) | 1 x 2 | |
| 左内腿 (inner-left-leg) | (5, 13) | 1 x 2 | |
| 右内腿 (inner-right-leg) | (9, 13) | 1 x 2 | |
| 右外腿 (outer-right-leg) | (11, 13) | 1 x 2 | |
| 地面阴影 | (3, 15) | 9 x 1 | 半透明黑色 |

### 设计约束
- **Clawd 没有嘴巴**，任何表情都不能添加嘴部元素。情绪完全通过眼睛形态、身体动态和特效传达。
- **优先用动作表达**：不使用对话气泡、说明框或长句。表达困惑、思考、疲惫等语义时，优先用歪头、眼睛节奏、手臂位置和身体停顿。确需点题时可加 2-4 字的简短飘浮文字（软约束，非硬禁止）。
- 手臂和腿在动画全程必须与躯干保持视觉连接，不能漂浮或断开。

### 结构特点
- 角色中心约在 x=7.5
- 双眼间距为 6 个单位 (x=4 到 x=10)
- 眼睛形状：普通睁眼为 1 宽竖矩形 (1x2)；持续半闭的眯眼/疲惫态可压扁加宽（如 1.5 宽的扁眼），眯眼本就需要更扁更宽
- 双臂与躯干之间无间隙 (左臂 x=0~2 紧贴躯干 x=2, 右臂 x=13~15 紧贴躯干 x=13)
- 四条腿成对分布，左侧两腿间距 2 单位，右侧同理，中间间距 4 单位
- 腿部 y=13 紧接躯干底部 y=13 (6+7=13)

### 变体姿态中的结构变化
- **站立动画**: 腿部通常延长为 1x3 (y=12 起)，与躯干有 1px 重叠确保连接
- **睡眠/摊倒**: 躯干变为宽扁形 (约 13x5)，腿缩为 1x1 小桩
- **过热**: 躯干完全横置 (x=1, y=10, 13x5)，眼睛变为叉号或细线
