# clawd-flying-kiss.svg

Clawd 抬右手到嘴边再向外送出一个飞吻，笑眼眯起、一颗像素爱心飞向右上方，3 秒循环。

## 身体结构
标准躯干 11x7 位于 (2,6)，`kiss-body` 随送吻方向轻微左右倾、`breathe` 呼吸。四腿 (x=3,5,9,11) `legs-bounce` 微跳。双眼有两套形态通过 opacity 切换：静止时普通 1x2 黑眼位于 (4,8)/(10,8)；送吻时切换为笑眼 ^^（polyline 描边，stroke 0.7）。左臂 (0,9) 轻摆，右臂 (13,9) 完成送吻动作并带 0.2 透明度投影。

## 道具
- **像素爱心**: 红色 (#E84057) 紧凑像素心形（约 5x3，顶部双凸起 + 满行 + 收窄 + 尖点），随 `heart-float` 从右手位置向右上飞出、放大再淡出。

## 动画
- **kiss-body (3s循环)**: 35% 微左倾（手靠近脸）→ 50% 右倾上送（吹吻瞬间）→ 恢复。
- **arm-kiss (3s)**: 右臂 30% 抬到脸边 translate(-4px,1px)（保持在眼睛下方）→ 50% 外伸上扬 translate(2px,-2px) 送吻 → 回落。
- **arm-l-sway (3s)**: 左臂轻微下沉摆动。
- **eyes-norm / eyes-hap (3s)**: 静止显示普通眼，25–75% 切换为笑眼 ^^（透明度互补切换）。
- **heart-float (3s)**: 爱心 52% 在手部位置出现 → 向右上飘移放大 → 85% 淡出。
- **legs-bob (3s)**: 双腿在送吻时微微上跳。
- **shadow-pulse (3s)**: 地面阴影轻微缩放。

## 动作表达
Clawd 把右手抬到嘴边、笑眼弯起，再向外一扬送出飞吻，一颗红色爱心从手中飞向右上方淡出——一个甜蜜、俏皮的送飞吻循环。
