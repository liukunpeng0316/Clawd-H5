# clawd-approved.svg

Clawd 举起绿色"通过"圆牌的满意动画，3秒循环。

## 身体结构
标准直立姿态，左臂静止在侧。右臂作为举牌支点（pivot 14,10），从身后270°逆时针挥到头顶。双眼两套切换：普通竖条眼 → 开心^^眼，通过 opacity+scaleY 眨眼过渡。眼睛有微小漂移（glance right → up → center）。

## 道具
- **木棍手柄**: 棕色(#795548) 水平连杆，(15,9.5) 5.5x1
- **绿色圆牌**: 双层圆形(#43A047/#4CAF50)，半径2.5/2，中心白色✓对勾
- **牌面闪光**: 白色圆点，随 shine-pulse 在牌到达顶部后两次闪烁

## 动画
- **身体摆动 (sway, 2.5s)**: scaleX 1-1.02, scaleY 1-0.98，轻微上下呼吸感
- **右臂举牌 (arm-swing-up, 3s)**: 0-33% rotate(180°)藏在身后 → 45% rotate(-95°)过冲到头顶 → 48% 回弹(-83°) → 52% 稳定(-90°) → 93% 保持 → 瞬切回身后
- **眼睛切换**: 0-31% 普通眼 → 31-35% 双眨眼过渡 → 35-93% 开心^^眼 → 93-95% 眨回 → 95-100% 普通眼
- **眼睛漂移 (eye-drift, 3s)**: 看右 → 眨眼时归中 → 看上方(看牌) → 归中
- **阴影 (shadow-breathe, 2.5s)**: scale 1-1.02

## 动作表达
Clawd 满意地从身后甩出一块绿色✓圆牌到头顶，眼睛从普通变为开心^^状态，欣赏地看向举起的牌子。
