# clawd-lion-dance.svg

Clawd 举着舞狮头欢快蹦跳的舞狮动画，0.6秒弹跳循环，含张嘴、踏步和金色纸屑。

## 身体结构
标准躯干 11x7 位于 (2,6)，#DE886D。四腿各 1x3 位于 (3,12)/(5,12)/(9,12)/(11,12)，比标准稍长，外侧两腿和内侧两腿交替踏步。双臂各 2x2 位于 y=7（左臂 (0,7)，右臂 (13,7)），抬高呈举狮头姿态。眼睛为开心 ^^ 形态，使用 polyline 绘制（stroke #000000, 0.8px）。地面阴影 13x1 位于 (1,15)，比标准宽（角色+狮头帷幔总宽度）。

## 道具
- **舞狮头**: 位于 Clawd 头顶上方，由多个组件构成：
  - **主体**: 17x7 红色块 (#E53935, rx=0.5) 位于 (-1,-8)
  - **金色顶冠**: 17x1.5 (#FFC107, rx=0.3) 位于 (-1,-9)，三个凸起（左 2x1.5 位于 (1,-10)，中 3x2 位于 (6,-10.5)，右 2x1.5 位于 (12,-10)）
  - **金色侧边**: 左右各 1x7 (#FFC107) 位于 (-1,-8) 和 (15,-8)
  - **狮眼**: 左右各 4x3 白底 (#FFFFFF, rx=0.5) 位于 (1,-6) 和 (10,-6)，黑色瞳孔各 2x2 (#000000, rx=0.3) 位于 (2.5,-5.5) 和 (11.5,-5.5)，带 pupil-bob 上下弹跳
  - **鼻孔**: 左右各 1x1 (#B71C1C) 位于 (6,-4) 和 (8,-4)
  - **上颌**: 15x1 (#FFD54F) 位于 (0,-2)，固定不动
  - **下颌**: 15x1.5 (#FFD54F) 位于 (0,-1)，带 mouth-chomp 开合动画；下颌上有 4 颗白色牙齿（各 1.5x0.8 #FFFFFF）位于 x=2/5/8.5/11.5
- **绿色帷幔**: 左右各 3x11 (#43A047) 从狮头垂下至角色两侧（左 (-1,0)，右 (13,0)），顶部各有 3x1 金色边 (#FFC107)，底部各有金色三角形锯齿装饰
- **金色纸屑**: 6 颗 1x1 像素粒子，颜色为 #FFD700/#FFC107/#FF6F00/#FFA000，分布在角色周围高处（y=-8 至 y=-14），各自带 CSS 自定义属性 --dx/--dy 控制飘散方向，animation-delay 从 0s 到 1.0s 间隔 0.2s 错开

## 动画
- **lion-bounce (0.6s循环, ease-in-out)**: transform-origin: 7.5px 15px。0%/100% 落地压扁(scaleY(0.92)) → 15% 弹射拉伸(scaleY(1.05)) → 40% 最高点(translateY(-8px) scaleY(1.02)) → 45% 滞留(scaleY(1)) → 70% 下落拉伸(scaleY(1.05)) → 85% 落地压扁(scaleY(0.92))。
- **step-outer (0.3s循环, ease-in-out)**: 外侧腿（左1/右4）交替抬起 translateY(-1.5px)，半周期循环。
- **step-inner (0.3s循环, ease-in-out)**: 内侧腿（左2/右3）与外侧反相，形成快速交替踏步。
- **mouth-chomp (0.6s循环, ease-in-out)**: transform-origin: 7.5px -1px。下颌在 40-50% 处下移 translateY(1.5px) 张嘴（对应跳跃最高点），其余时间闭合。
- **pupil-bob (0.6s循环, ease-in-out)**: 瞳孔在 40-50% 处上移 translateY(-0.5px)，与弹跳同步。
- **shadow-lion (0.6s循环, ease-in-out)**: 0%/85%/100% 正常(scale(1) opacity 0.5) → 40-45% 最高点极小(scale(0.5) opacity 0.2)。
- **confetti-burst (1.2s循环, ease-out)**: 6 颗纸屑各自从初始位置出发，10% 处 opacity 1 完全显现，之后沿 --dx/--dy 方向飘散并缩小至 scale(0.3) 消失。每颗间隔 0.2s 依次触发，形成持续撒花效果。

## 动作表达
Clawd 双手高举红色舞狮头欢快蹦跳，绿色帷幔随身体摆动，狮嘴在最高点张开，金色纸屑四散飞扬，洋溢着喜庆的节日氛围。
