# clawd-kick-football.svg

Clawd 抬右腿把足球向左踢出，4 秒循环，身体先蓄力后倾再前送，撞击点迸出火花。

## 身体结构
标准躯干 11x7 位于 (2,6)，fill=#DE886D，整体 `body-kick` 随踢腿前后倾压扁。双眼为标准 1x2 黑色矩形位于 (4,8)/(10,8)，随球左右扫视并在踢中瞬间 scaleY 眯起。四腿分两组：左腿对 (x=3,5) 支撑、右腿对 (x=9,11) 绕 (10,12) 大幅摆动完成踢球。双臂 2x2 位于 (0,9)/(13,9) 左右平衡摆动。

## 道具
- **足球**: 白色圆形 (cx=1,cy=14,r=2) + 深灰描边 (#333333) + 两块黑色五边形拼块 (path)，随 `ball-move` 从右向左飞、`ball-spin` 逆时针旋转。
- **撞击火花**: 3 颗金色小方块 (#FFC107)，仅在踢中瞬间 (48–57%) 于左下撞击点闪现飞散。

## 动画
- **kick-body (4s循环)**: 25% 起蓄力，38% 微后倾，48% 前送 (rotate -4deg)，再恢复。
- **legs-right-kick (4s)**: 右腿对 38% 后摆 -30° 蓄力 → 48% 前踢 +40° → 回落。
- **legs-left-kick (4s)**: 支撑腿微抬维持平衡。
- **arm-l-balance / arm-r-balance (4s)**: 双臂反向摆动维持平衡。
- **ball-move (4s)**: 球从 translate(14px) 滚近，48% 被踢后向左加速至 -22px。
- **ball-spin (4s linear)**: 球持续逆时针旋转（踢出后加速）。
- **eyes-watch (4s)**: 双眼随球从右扫到左，踢中瞬间 scaleY(0.7) 眯起。
- **spark-1/2/3 (4s)**: 撞击瞬间三颗火花向左上飞散淡出。
- **shadow-kick-anim (4s)**: 地面阴影在踢中瞬间略微放大。

## 动作表达
Clawd 盯着滚来的足球，蓄力后抬右腿将球向左踢飞，撞击点迸出火花，身体随踢腿前倾再恢复站立。
