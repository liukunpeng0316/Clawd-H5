# clawd-innocent-blink.svg

Clawd 天真歪头眨眼、身后花朵分波涌出的动画，2.5秒循环。

## 身体结构
标准躯干带呼吸(3.2s)。body-tilt 2.5s rotate(±6°) 左右歪头，在两端停留(18-40% 与 60-82%)。眼睛带白色高光（无辜眼），每次歪头中各眨一次 scaleY(0.1)，整周期共两次眨眼(23%/33% 与 65%/75%)。

## 道具
- **花朵**: 4 朵两组——大花组（粉 #FFB6C1 + 紫 #D8BFD8），小花组（蓝 #A0C4FF + 白 #FFFFFF），均带黄色花心 (#FFE066)，围绕身体 (7.5, 10) 散布

## 动画
- **breathe (3.2s)**: 标准呼吸
- **body-tilt (2.5s)**: rotate(±6°) 左右歪头并在两端短暂停留
- **eyes-blink (2.5s)**: 每次歪头两次 scaleY(0.1) 眨眼
- **flower-rise (2.5s linear)**: 花朵 translate 0 → -14px 上升并淡出，分两批 delay 0s 与 1.25s 错开形成涟漪般的两波

## 动作表达
Clawd 天真地左右轻歪着头，眼睛闪烁着白色高光，每次歪头都缓缓眨一下，身后两组花朵——大花和小花——分两波缓缓向上飘起又淡淡消失。
