# clawd-charge.svg

Clawd 系着红色头带在画面内向上飞冲的"冲！"动画，2秒循环。

## 身体结构
标准躯干与四腿。左臂高举超人姿势(rotate -85°, translate -1,-2)，右臂向后拖曳(rotate 25°, translate -1,1)，右臂带手影。双眼有 scaleY 0.8-1 脉冲（坚定闪烁）。整个角色使用 clipPath 裁剪，但全周期保持角色本体可见。

## 道具
- **红色头带**: 暗红(#B71C1C) 横条 (1,6.5) 13x1，覆盖额头
- **头带飘尾**: 两条(#B71C1C/#8B0000) 从右侧飘出，0.3秒 flutter 抖动(15°-25°/20°-35°)
- **速度线**: 6条金色(#FFD700/#FFA000/#FFC107) 细长矩形，0.4秒向下 streak 动画
- **火花尾迹**: 3颗金色(#FFD700/#FFC107/#FFF59D) 小方块，从角色下方浮出并缩小消失

## 动画
- **飞行 (fly, 2s)**: translate(0,7px) → 线性上冲带±0.4px横向摇晃 → 到达(-12px) → 回落到 translate(0,7px)，全周期角色可见
- **头带飘动 (flutter1/flutter2, 0.3s)**: rotate 15°-25° / 20°-35°，0.1s 延迟错开
- **眼睛闪烁 (eyes-shine, 0.8s)**: scaleY 1→0.8→1
- **速度线 (streak, 0.4s)**: translateY 0→8px, opacity 0.9→0
- **火花尾迹 (trail-spark, 0.6s)**: 从隐形浮出 → opacity 0.9 → translateY 5px 缩小消失

## 动作表达
Clawd 系着飘动的红色头带，以超人姿势在画面内向上飞冲，周围金色速度线呼啸而过，身后留下闪烁的火花尾迹。
